Cafe Ordering Application System:
A database-driven web application designed to streamline cafe operations which allow customers to browse menu,
place order and checkout and at the same time provides administrative functionality such as track, review
and update order statuses.

Features:
Customer interface - Interactive menu browsing, checkout system and order confirmation,
Admin dashboard - Managing menu items, such as edit, delete, add menu and tracking orders,
Database management - Relational database schema with full integrity constraints

Environment:
XAMPP - Apache, MySQL

Languages:
CSS, PHP, HTML, JavaScript

Database:
MySQL

File structure:
index.php - main menu page,
checkout.php - order summary and checkout processing,
admin_dashboard.php - administrative management page,
manage_menu.php - to add, edit or delete menu items,
cafe_ordering_system.sql - complete SQL database creation
